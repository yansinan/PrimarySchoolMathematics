# v2.3.0 — 出题抽屉信息架构定稿

> 接 v2.2.0，本版只做出题抽屉/交互的收口，外加错因与错题库的两处修正。

## 出题抽屉（信息架构）

- **题目来源**三段分页：`错题库 / 自动生成 / 手动添加`
- **自动生成页 = 两块平级工具**：
  - 「已保存的配置」：配置快照（自动生成这套参数），点选即载入并自动切回本页
  - 「出题配置」：几步运算 / 取值范围 / 出题规则 / 数量 —— 一张卡片内用「段标题 + 分隔线」分组，不套娃
- 三个分页的「添加口算题（N 题）/ 清空口算题」都在卡片**外**、内容下方，位置一致
- 「保存为配置」留在出题配置卡内（原「将当前参数保存为配置」）
- 底部出口条独立成条（分隔线 + 浅底）：`打印练习卷（N 份）` / `开始互动练习（N 组）`
- 「当前口算题包含的内容」→ **已添加的题组（N）** 卡片，标签可 ✕ 删除
- 行距全量统一为 **12px**（相邻区块逐个实测，详见 17 号文档 §十四）
- 修正取值范围表格内「最小值/最大值」错行 5px 的问题（CSS 优先级误伤表格单元格）

## 错因与错题库

- 选择题也有错因：根因是错因只读了 `session.currentAnswer`（选择题不写该字段）
- 答错常驻错因条：留到「答对」或「换题」才消失（不再跟反馈计时）
- 错题库：行显示「算式 + 划掉的错误答案 + 错因 + 掌握度(历史正确率)」，
  运算符筛选、4 种排序、点击/Shift 连选/全选/选 N 题自动选择、加入练习后可混排
- 修 `paperGenerator` 丢自定义题组的老 bug（手动添加/错题库的题此前不进卷子也不进练习）
