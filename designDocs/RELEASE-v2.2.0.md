# v2.2.0 — 准备页改版 + 错因体系 + 错题库

> 分支 `feat/start-page-redesign`（36+ commits）。汇总 2026-11-26 ~ 11-27 的改动。

## 练习前（准备开始页）

- 删掉「这次练什么」，信息并入**默认折叠**的「本次练习设置」
- 「练习重点」上移到学习情况正下方
- 指标卡：历史正确率 → **上次正确率**（最近一轮）
- 档位支持 **降一档 / 升一档**，`▾` 里放起点档位 / 恢复自动
- **档位配比**迁入设置区（24 档层，限高 260px 内部滚动）
- 灰色说明全部改成 **ⓘ 点击气泡**

## 出题抽屉

- 「其他设置」二级抽屉**删除**，出题规则内联折叠（点击层级 3 → 0）
- 数字范围改成表格（6 行 → 3 行）；口算题数 / 卷子份数并排一行放最后
- 卷子标题 / 副标题 / 卷数 / 列数 / 文件名规则 → 「生成卷子」对话框
- 题目来源分页：**错题库 / 自动生成 / 手动添加**
- 已添加题组可**单个删除**（✕）；点「已保存的配置」自动切回自动生成页并载入参数

## 练习中

- 自定义练习**按卷子分组**，每组结束自评，进度按本组算，类型显示「自定义」
- 进度：≤10 题数字小格 / >10 题细条，**不再溢出**
- 组徽标：自定义 `第 2 组，共 3 组`；自适应 `难度 · 第 N 组 · X/Y 题`
- **答错即时错因**：常驻错因条（留到答对/换题）+ toast，文字/竖式/**选择题**全覆盖
- 错题复习**整题高亮**（橙色底 + 描边 + 「重点复习」徽标）
- 干扰项按**真实错因**生成（忘进位 / 忘退位 / 口诀串行 / 把×当+ / 余数当商…）
- 全流程**可全键盘操作**（自评 ←/→ + Enter，汇总同）

## 打印

- 「打印练习卷」在**新窗口**打开，配置页留在原处（数据经 localStorage 跨标签页传递）
- 修 `paperGenerator` 丢自定义题组的老 bug（手动添加/错题库的题现在能打印也能练）
