# 准备开始页改版（去重 / 上次正确率 / 折叠设置区 / 升降档）

> 分支：`feat/start-page-redesign`　　设计图：[`mockups/start-page/`](mockups/start-page/)
> 实现截图：`impl-collapsed-390.png` / `impl-expanded-390.png` / `impl-collapsed-1440.png` / `impl-expanded-1440.png`

## 一、起因

准备开始页有三处重复与一处误导：

1. 「目前学习情况」的 Lv 卡与「这次练什么」里的档位 chip **同一信息出现两次**；
2. 「这次练什么」那行 chip（题量 / 组量 / 只练本档 / 升档方式）与上下两个区块**都是重复**；
3. 第二个指标卡写「历史正确率」，是**全部历史平均**，孩子看到 100% 会误判自己当前水平；
4. 自适应设置藏在「绿色浮动按钮 → 测试生成 → 其他设置 → 练习档位折叠」**四步之后**，主流程里根本找不到。

## 二、改了什么

### 2.1 页面结构（手机与桌面完全相同）

```
准备开始
────────────────────────
目前学习情况   [Lv.10] [43%] [1天]
练习重点       [乘法口诀·2~6]
────────────────────────
▸ 本次练习设置   只影响本次练习        ← 默认折叠
  [Lv.10 乘法口诀·2~6][10~30 题][每组 4~10 题][只练本档][手动升档]
────────────────────────
[          开始练习          ]          ← sticky 吸底
```

- **删掉「这次练什么」整块**，它那 5 个 chip 的信息全部并进折叠摘要；
- **「练习重点」上移**到状态卡正下方 —— 那是孩子该关注什么，不是设置；
- 状态卡第二个指标改为 **上次正确率**；
- 自适应四项设置进「本次练习设置」，默认折叠，只占标题 + 一行摘要。

### 2.2 展开态（5 行，宽屏窄屏同一套）

| 行 | 内容 |
|---|---|
| 档位 | `Lv.N` + **降一档 / 升一档** + `▾`（更多档位控制） |
| 挑战题 / 自动升档 | 两个开关并排，各带 ⓘ |
| 题量 | `[最少] ~ [最多] 题`，改完即时保存 |
| 每组 | `4~10 题`（只读，按表现自动调整） |

灰色说明全部收进 **ⓘ 点击气泡**（不用 hover：平板没有 hover）。共 4 处：挑战题、自动升档、题量、每组。

### 2.3 降一档 / 升一档的语义

- 写入同一个 `psm_level_override`（起点档位）覆盖，`since` 刷新 → 旧轮次不再参与升档阶梯；
- 边界：0 档时「降一档」置灰（tooltip「已是最低档」），最高档时「升一档」置灰；`自动升档`打开时两个都置灰；
- 反馈：升档 `playSfx('levelup')`，降档 `playSfx('tap')`（不给孩子"退步"的负面音效）；
- 「降一档」用中性灰，不用红色 —— 降档是正常的调整，不是惩罚。

### 2.4 「更多档位控制」（`▾`）

低频操作放进小面板，不常驻：

- **起点档位**：按年级分组的 `el-select`，默认「自动（按练习记录计算）」；
- **应用**：写入覆盖并提示「下次开始练习生效」；
- **恢复自动**：清除覆盖（写墓碑，能同步到其它设备）。

### 2.5 宽屏排版：方案 A「窄栏居中」

按 [agentmux 宽屏 Settings 规格](https://github.com/agentmuxai/agentmux/blob/813b3bb2d39b01e922582679a1d9856261ce2eb5/docs/specs/SPEC_SETTINGS_WIDE_PANE_COLUMNS_2026_11_20.md) §3.2 — 宽屏优先「一行一列、列宽可读」，不是「填满宽度」。

卡片沿用既有 `.practice-card--start { max-width: 560px }`，**零新增宽屏 CSS**；桌面与手机同一份标记与样式。

## 三、数据流

### 3.1 上次正确率

`services/statsAggregator.js#getLastSessionAccuracy(studentId, maxRounds = 10)`

```
PracticeSession.list（倒序、同 practiceSessionId 合并）
  → 逐轮找第一条「有答题」的轮次
  → 答案按 sessionId_equation_solution_questionIndex 去重
  → { accuracy, total, correct, at }，无历史 → accuracy: null
```

诊断答案不挂 `practiceSessionId`，天然不会被算进来。

### 3.2 练习量的单一写路径

准备页改题量时**不做整份表单覆盖**：

```
targetDraft → validateTargetRange() 校验
  ├─ 不通过 → 就地标黄，不写盘
  └─ 通过   → practiceStore.setAdaptiveTarget(min, max)   （实时，本次练习用）
             + patchFormState({ targetMin, targetMax })  （合并写 psm_form_state，刷新后保留）
```

读侧优先级：`adaptiveTarget`（实时）→ `adaptiveConfig`/`configSnapshot`（诊断快照）→ `psm_form_state` → 默认 10/30。

`Generate.vue` 增加了反向同步：**抽屉打开时**把 `targetMin/Max` 从 `psm_form_state` 刷一遍，避免抽屉拿着挂载时的旧值把准备页的改动覆盖掉。

### 3.3 存储键

无新增。用到的仍是：`psm_level_override`、`psm_challenge_enabled`、`psm_auto_advance`、`psm_form_state`。全部经 `settingsRegistry.writeSetting`，多设备同步语义不变。

## 六、出题抽屉里的档位区：已隐藏（观察期到 2026-12-30）

`OptionsDrawer.vue`（「其他设置」抽屉）里的 **练习档位区**（起点档位 / 挑战题 / 自动升档 / 升一档）
已于 2026-11-26 整块注释，页面上不再出现。

- **为什么**：这些入口已经迁到「准备开始」页的「本次练习设置」，抽屉里再留一份就是两个入口改同一个设置，容易互相矛盾；
- **怎么保留**：整块用一个 HTML 注释包起来，注释头部写清隐藏原因、恢复方式、以及将来删除时要一并清掉的
  script 变量 / 样式段 / import 依赖（HTML 注释不能嵌套，块内原有的两行小注释已并入头部说明）；
- **到期**：**2026-12-30** 若没有需要回滚的问题，整块删除。期间要回滚只需把注释去掉。

验证：抽屉打开后页面文本中不再出现「练习档位 / 起点档位 / 挑战题 / 自动升档」，「档位配比」仍在，console 无新增报错。

## 七、档位配比搬进练习设置（A）

`OptionsDrawer.vue` 的「档位配比」（24 档）搬到准备页「本次练习设置」里：

- 展开设置区后出现一行 `档位配比 [N 档已自定义] ⓘ … 展开/收起`；
- 点开展开是第二层，24 档按年级分组，**`max-height: 260px` 内部滚动**（实测 scrollHeight ≈ 1019px，页面高度不变）；
- **设置区收起时整块不渲染**，折叠摘要里也不放配比信息；
- 改某档系数即时写 `psm_level_coefficients`（只落非默认值），行上标签变为「1 档已自定义」；
- 「恢复默认」清空表（写墓碑，可同步），标签消失。

读写仍走既有 `utils/store/levelCoefficients.js`（`loadLevelCoefficients` / `saveLevelCoefficients` / `clearLevelCoefficients`），无新增存储键。

## 八、卷子专属配置搬进「生成卷子」对话框（B2）

抽屉里只保留「自定义练习 + 卷子」**共用**的配置（题型/括号/进位/退位/解法）。卷子独有的五项收进对话框：

| 项 | 位置 |
|---|---|
| 卷子数量 | 生成卷子对话框 |
| 每行列数 | 生成卷子对话框 |
| 文件名规则 | 生成卷子对话框 |
| 卷子标题 | 生成卷子对话框 |
| 副标题 | 生成卷子对话框 |

点「生成卷子」→ 先挡掉空题单 / 超 1000 题 → 弹对话框（带上次填过的值）→ 确认后走原有 `generate()` 跳 `/print`。

⚠️ **已知遗留（已记 TODO · U1）**：`generateFormulas`（开始练习）也乘 `numberOfPapers`，所以「卷子数量」现在仍影响练习长度。计划改成「几张卷子 = 几组练习」，练习与打印共用同一份分组配置，再把该字段移回共用区。

## 九、出题抽屉紧凑化 + 干掉「其他设置」二级抽屉

**数字范围表格化**（`AutoGenerateFormulas.vue`）

原来三组范围各占两行、六个带前缀的大输入框：`算数项1 最小值/最大值`、`算数项2 …`、`运算结果 …`。
改为一张表，表头共用一次：

```
数字范围      最小值   最大值
算数项 1       [ 1 ]   [ 9 ]
算数项 2       [ 1 ]   [ 9 ]
运算结果       [ 1 ]   [ 9 ]
```

- 6 行 → 3 行，手机上不再被 `xs=24` 折成两行
- 校验仍然生效：单元格里保留 `ElFormItem :prop/:rules`，错误信息**绝对定位**不撑行高
- 输入框居中、等宽数字（`tabular-nums`）

**出题规则内联**（原「其他设置」二级抽屉）

- 「几步运算」右侧的 **其他设置** 按钮删除，`OptionsDrawer.vue` **整文件删除**（含之前在观察期的两块注释代码）
- 6 项（题型 / 括号 / 进位 / 退位 / 除法 / 解题方式）内联成抽屉里一个默认折叠的 **出题规则**：
  - 折叠时用 badge 显示当前选择（`求结果 · 随机进位 · 随机退位 · 口算解题`，带括号时多一个 `带括号`）
  - 展开就是 6 行控件
- 点击层级从 **3 级降到 0 级**（参数直接在主抽屉里）
- 原 Rules 规则原样搬过来：求算数项时不能有余数、多步运算不能有余数、除法只支持整除

✅ 顺带：`utils/store/{levelOverride,challengeSetting,autoAdvance}.js` 的 `@see` 从 OptionsDrawer 改指 `Practice.vue`。
